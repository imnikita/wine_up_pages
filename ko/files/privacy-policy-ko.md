# 개인정보 처리방침

**VinoPrep – WSET 시험 준비 앱**

**최종 수정일：** 2026년 2월 18일

## 제1조 (목적)

VinoPrep(이하 "당사" 또는 "저희")는 WSET(Wine & Spirit Education Trust) 인증 시험을 준비하는 사용자를 위한 독립적인 교육용 모바일 애플리케이션입니다. 본 개인정보 처리방침은 서비스 이용 과정에서 수집·이용·보관·공유되는 데이터에 관한 사항을 안내합니다.

**VinoPrep은 계정 등록이 필요하지 않습니다.** 프로필 생성, 이메일 주소 입력, 비밀번호 설정이 일체 필요 없습니다. 따라서 당사는 귀하를 개인으로 직접 식별할 수 있는 개인정보를 보유하지 않습니다.

> **음주 관련 콘텐츠에 대한 고지:** VinoPrep은 교육 목적의 시험 준비 도구입니다. 와인 및 주류에 관한 모든 콘텐츠는 WSET 커리큘럼에 기반한 순수한 학술적 맥락에서 제공됩니다. 서비스를 이용함으로써 귀하는 해당 지역 법정 음주 가능 연령(대한민국 만 19세, 일본 20세, 기타 지역 18세)에 달했음을 확인합니다.

## 제3조 (이용 가능 연령)

VinoPrep은 다음 최소 연령 요건을 충족하는 이용자에게만 제공됩니다：

| 국가/지역 | 최소 연령 |
|---|---|
| 대한민국 | 만 19세 이상 |
| 일본 | 만 20세 이상 |
| 기타 모든 지역 | 만 18세 이상 (또는 해당 지역 법정 음주 가능 연령 중 높은 쪽) |

당사는 연령 요건을 충족하지 않는 이용자의 데이터를 의도적으로 수집하지 않습니다. 자녀가 본 앱을 이용하고 있다고 생각되시면 support@vinoprep.com 으로 즉시 연락해 주십시오.

## 제4조 (수집하는 데이터)

VinoPrep에는 계정 시스템이 없으므로 수집되는 모든 데이터는 **익명 또는 가명** 처리됩니다. 특정 개인이 아닌 기기 또는 무작위로 생성된 식별자에 연결됩니다.

### 4.1 자동으로 수집되는 데이터

**학습·진도 데이터 (기기 내에만 저장)**

- 플래시카드 학습 이력 (열람 카드, 정답·오답 기록, 간격 반복 알고리즘용 난이도 점수)
- 퀴즈 및 모의시험 결과·점수·타임스탬프
- 학습 세션 시간 및 빈도
- 진도 달성 현황 및 완료 통계

이 데이터는 **귀하의 기기 내에만** 로컬 스토리지(Core Data)에 저장됩니다. 당사 서버로 전송되거나 제3자와 공유되지 않습니다.

**구독·결제 데이터 (RevenueCat 경유)**

인앱 구매 또는 구독 시 구독 관리 서비스인 RevenueCat이 거래를 처리합니다. RevenueCat이 수신하는 데이터：
- 익명 App User ID (무작위 생성, 개인 정보와 연결되지 않음)
- 구매·구독 상태
- App Store / Google Play 거래 메타데이터

RevenueCat은 귀하의 성명, 이메일 주소, 결제 카드 정보를 수신하지 않습니다. 해당 정보는 Apple 또는 Google이 관리합니다.
RevenueCat 개인정보 처리방침：https://www.revenuecat.com/privacy

**페이월·전환 이벤트 (Superwall 경유)**

Superwall은 앱 내 페이월의 관리 및 표시에 사용됩니다. Superwall이 수집하는 데이터：
- 익명 기기 식별자
- 페이월 노출 및 전환 이벤트
- 페이월 상호작용과 관련된 앱 세션 데이터

Superwall 개인정보 처리방침：https://superwall.com/privacy

**앱 이용 분석 (Firebase Analytics 경유)**

Firebase Analytics는 앱 이용 현황 파악 및 개선을 위해 익명화된 이용 데이터를 수집합니다：
- 기능 이용 이벤트 (예：플래시카드 덱 열람, 퀴즈 시작 등)
- 세션 수 및 시간
- 기기 종류, OS 버전
- 국가 수준의 위치 정보 (IP 주소 기반 추정, IP 주소 자체는 저장되지 않음)
- 앱 버전

Firebase Analytics는 성명, 이메일 등 직접 식별 가능한 정보를 수집하지 않습니다. 기기 광고 설정(iOS：추적 제한 / Android：광고 맞춤 설정 해제)을 통해 옵트아웃할 수 있습니다.
Google 개인정보 처리방침：https://policies.google.com/privacy

**충돌 보고서 (Firebase Crashlytics 경유)**

Firebase Crashlytics는 앱 충돌 또는 오류 발생 시 기술적 데이터를 수집합니다：
- 기기 종류, OS 버전
- 충돌 시점의 앱 버전
- 스택 추적 및 오류 로그
- 무작위로 생성된 설치 식별자

이 데이터는 오류 진단 및 수정 목적으로만 사용됩니다.
Google 개인정보 처리방침：https://policies.google.com/privacy

### 4.2 수집하지 않는 데이터

- 성명, 이메일 주소, 기타 연락처 정보
- 비밀번호 또는 인증 정보
- 결제 카드 정보 또는 은행 정보
- 정밀 GPS 위치 정보
- 카메라, 마이크, 연락처 데이터
- 귀하를 직접 식별할 수 있는 모든 정보

## 제6조 (데이터 공유)

당사는 귀하의 데이터를 판매하지 않습니다. 데이터는 아래 제3자 서비스 제공업체와만 위에서 설명한 목적 범위 내에서 공유됩니다.

| 제공업체 | 역할 | 개인정보 처리방침 |
|---|---|---|
| **RevenueCat** | 구독·결제 관리 | https://www.revenuecat.com/privacy |
| **Superwall** | 페이월 관리·전환 분석 | https://superwall.com/privacy |
| **Firebase Analytics** (Google) | 익명 이용 현황 분석 | https://policies.google.com/privacy |
| **Firebase Crashlytics** (Google) | 충돌 보고·진단 | https://policies.google.com/privacy |
| **Apple App Store** | 결제 처리 (iOS) | https://www.apple.com/legal/privacy/ |
| **Google Play Store** | 결제 처리 (Android) | https://policies.google.com/privacy |

각 제공업체는 지정된 목적 범위 내에서만 데이터를 이용하고 적절한 보안 기준을 유지하도록 계약상 의무를 지고 있습니다.

## 제8조 (이용자의 선택권 및 권리)

VinoPrep은 당사 고유 서버에 개인 식별 정보를 수집·저장하지 않으므로, **당사는 개별 이용자를 식별할 수 없습니다.** 따라서 신원 확인에 기반한 개인정보 열람·정정·삭제 요청에 직접 응하는 것은 기술적으로 어렵습니다.

다만, 다음의 실질적인 수단을 이용하실 수 있습니다：

**로컬 데이터 삭제：** 앱을 삭제하면 기기에 저장된 모든 학습 진도와 설정이 삭제됩니다.

**분석 옵트아웃：** 다음 기기 설정을 통해 분석 데이터 수집을 제한할 수 있습니다：
- iOS：설정 → 개인정보 보호 및 보안 → 추적 → VinoPrep 추적 비활성화
- Android：설정 → Google → 광고 → 광고 맞춤 설정 해제

**구독 관리：** 구독은 Apple ID 또는 Google 계정을 통해 관리됩니다. 기기의 구독 설정에서 언제든지 해지할 수 있으며 당사에 별도로 연락하실 필요가 없습니다.

**문의：** 데이터 처리에 관한 질문이 있거나 데이터가 부적절하게 처리되었다고 생각되시면 support@vinoprep.com 으로 연락해 주십시오. 30일 이내에 응답하며 기술적으로 가능한 범위에서 최대한 대응하겠습니다.

## 제9조 (국제 데이터 이전)

## 제10조 (보안)

당사는 서비스와 관련된 데이터를 보호하기 위해 다음의 기술적 조치를 시행합니다：
- 로컬 학습 데이터는 기기의 암호화 저장소에 보관
- 모든 네트워크 통신에 TLS 암호화 사용
- 보안 검증을 거친 신뢰할 수 있는 제3자 SDK 사용

어떠한 시스템도 100% 안전하지 않습니다. 보안 문제를 발견하신 경우 support@vinoprep.com 으로 알려 주시기 바랍니다.
